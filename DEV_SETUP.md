# THE LAST DROP — Dev Tools Setup

Already on this machine: **Godot 4.7.2 + export templates, Android SDK (adb, sdkmanager), Java, Node 26, git.**

## Add these yourself (one-time, ~10 min)

| # | What | Command | Why |
|---|---|---|---|
| 1 | **Godot MCP** (Coding-Solo) | `claude mcp add godot -e GODOT_PATH=$(command -v godot) -- npx @coding-solo/godot-mcp` | Claude can launch the project, read Godot's errors/output and edit scenes. The biggest speed-up for the 12h build. Restart Claude Code after adding. |
| 2 | **Cloudflare plugin** (official marketplace) | `/plugin install cloudflare@claude-plugins-official` | Skills for Workers, Durable Objects and Wrangler: exactly the online/5G server. |
| 3 | **Cloudflare account + Wrangler login** | Sign up free at dash.cloudflare.com, then `! npx wrangler login` | Interactive browser login; only you can do it. Needed to deploy the game and the server. |
| 4 | **Disable unused MCPs for this project** | `/mcp` → disable **vercel** (200+ tools), Google Drive, Microsoft 365, easel | Keeps Claude's context free for game code. We host on Cloudflare, not Vercel. |
| 5 *(optional)* | Godot skills plugin (community) | `/plugin marketplace add Randroids-Dojo/Godot-Claude-Skills` then `/plugin install godot` | GdUnit4 testing, exports, PlayGodot automation. Third-party: read its skill files before installing. |
| 6 *(optional)* | Pixelify Sans font | https://fonts.google.com/specimen/Pixelify+Sans → into `assets_candidates/9_manual/fonts/` | Readable body text on phones. |

**Skip:** Aseprite MCP servers (they need paid Aseprite; sprites are generated by `assets_candidates/10_generated/gen_sprites.py` instead) and the Vercel MCP.

## Testing stack (Claude installs it during project setup)

- **gdUnit4** (Godot addon) for unit tests, runnable headless: `godot --headless -s res://addons/gdUnit4/bin/GdUnitCmdTool.gd`
- **gdtoolkit** (`gdlint`, `gdformat`) in a local venv for GDScript linting.
